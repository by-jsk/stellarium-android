# PC 기능 이식 및 검증표

기준: `source.lock.json`에 기록한 공식 PC 소스. 다음은 목표 및 현재 검증 상태입니다. 컴파일 성공만으로 모든 기기에서의 기능 동작을 보장하지 않습니다.

| 기능 | 구현 경로 | 현재 검증 |
|---|---|---|
| 별·태양계·심원천체·은하수·대기·지평선 | 실제 PC 엔진 및 기본 데이터 | ARM64/x86 빌드, 태양·달·화성·시리우스·M31 로딩/유한 좌표, 실제 하늘 화면 확인 |
| 별자리·다양한 하늘 문화·다국어 천체 이름 | PC 데이터 및 번역 | 데이터/번역 포함 검사, 별자리 선 토글 통과; 모든 하늘 문화의 개별 화면은 미검증 |
| 천체 검색·선택·추적·핀치 확대·드래그 이동 | PC 엔진 + 모바일 조작 | 엔진의 5개 천체 검색 통과; 모든 터치 조작의 S25 실기기 검증은 별도 필요 |
| 날짜·시간 속도·관측 위치·GPS | PC 엔진 + 모바일 입력 | J2000 시간 설정/UTC 왕복/관측지 시간대/서울 도시 DB 통과; 실외 GPS 수신 미검증 |
| 천문 계산·관측 목록·접안렌즈·위성·유성우 등 | 기본 PC 플러그인 및 터치 동작·즉시 로드 목록 | 29개 기본 플러그인 빌드, 363개 동작 등록과 AngleMeasure 즉시 로드 통과; 나머지 개별 현장 검증 필요 |
| PC의 상세 설정·스크립트 콘솔·플러그인 설정 | 스크롤 가능한 상세 패널 | 컴파일·진입 동작 유지; 모든 상세 화면/스크립트의 실행 검증 미완료 |
| 한·영·일·중·서·러 / 국가·언어 분리 | 모바일 번역 + PC 번역 | 6개 언어/설정 순서/영어 폴백/한글+일본 지역 독립 저장 통과, 한글 화면 캡처 확인 |
| 적색 야간 화면·밝기·패널 닫기 | 화면 전체 적색 셰이더 + Android 밝기 + 터치 × | Android 16 및 실제 16KB 에뮬레이터에서 비적색 픽셀 비율 0, 실제 닫기 터치와 하늘 복귀 통과 |
| 앱 내 업데이트·동일 서명으로 데이터 유지 | HTTPS 메타데이터 + Android 설치기 | CI의 이전 코드 0 → 1 다운로드/설치 확인/완료/한글·지역 보존 통과; 배포키 인증서는 별도 고정 검증 |
| ShowMySky 고급 대기 | Android GLES 미지원(공식 소스 제한), 기본 대기 모델 사용 | 제외 |
| Windows 전용 ASCOM / Spout, Oculus PC 장치 | 해당 운영체제·하드웨어 전용 | 제외 |
| 실제 망원경 제어 | 지원 프로토콜을 유지하되 실제 장치 테스트 필요 | 미검증 |

기본 카탈로그 이외의 추가 대용량 카탈로그, 온라인 서버 기능, 특정 하드웨어는 별도 데이터·연결이 필요할 수 있습니다.
