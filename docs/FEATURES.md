# PC 기능 이식 및 검증표

기준: `source.lock.json`에 기록한 공식 PC 소스. 다음은 목표 및 현재 검증 상태입니다. 컴파일 성공만으로 모든 기기에서의 기능 동작을 보장하지 않습니다.

| 기능 | 구현 경로 | 현재 검증 |
|---|---|---|
| 별·태양계·심원천체·은하수·대기·지평선 | 실제 PC 엔진 및 기본 데이터 | 빌드 대기 |
| 별자리·다양한 하늘 문화·다국어 천체 이름 | PC 데이터 및 번역 | 빌드 대기 |
| 천체 검색·선택·추적·핀치 확대·드래그 이동 | PC 엔진 + 모바일 조작 | 빌드 대기 |
| 날짜·시간 속도·관측 위치·GPS | PC 엔진 + 모바일 입력 | 빌드 대기 |
| 천문 계산·관측 목록·접안렌즈·위성·유성우 등 | 기본 PC 플러그인 및 터치 동작 목록 | 빌드 대기 |
| PC의 상세 설정·스크립트 콘솔·플러그인 설정 | 스크롤 가능한 상세 패널 | 빌드 대기 |
| 한·영·일·중·서·러 / 국가·언어 분리 | 모바일 번역 + PC 번역 | 빌드 대기 |
| 앱 내 업데이트·동일 서명으로 데이터 유지 | HTTPS 메타데이터 + Android 설치기 | 빌드 대기 |
| ShowMySky 고급 대기 | Android GLES 미지원(공식 소스 제한), 기본 대기 모델 사용 | 제외 |
| Windows 전용 ASCOM / Spout, Oculus PC 장치 | 해당 운영체제·하드웨어 전용 | 제외 |
| 실제 망원경 제어 | 지원 프로토콜을 유지하되 실제 장치 테스트 필요 | 미검증 |

기본 카탈로그 이외의 추가 대용량 카탈로그, 온라인 서버 기능, 특정 하드웨어는 별도 데이터·연결이 필요할 수 있습니다.
